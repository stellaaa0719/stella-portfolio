# Stella 个人作品集

个人域名：https://zuojunli.com

备用预览：https://stellaaa0719.github.io/stella-portfolio/

纯静态 HTML / CSS / JavaScript，无依赖安装或构建步骤。

## 页面结构

单页结构：星空封面 → 个人介绍 → 产品经历（模拟工作台、成果与口径）→ 工具应用 → 联系方式。原有 HTML 地址继续兼容同页入口。

- `star-cover.js/css`：世界星图封面与阅读背景。
- `platform-demo.html/css/js`：独立静态模拟工作台，九个可点击业务模块。
- `portfolio-workbench.js/css`：嵌入工作台的自适应高度、同页体验入口与成果对比。
- `profile.css`、`mist-theme.css`、`single-page.css`：个人品牌、履历和整站布局。
- `single-page.js`：微信点击显示与联系方式复制。
- `assets/`：毕业照、简历及现有静态附件。

### 模拟工作台

AI 工作台保留四个场景；业务模块包含今日工作台、客户、商机、项目、每日资讯、情报中心、材料工作台与数据看板。跟进待办合并到今日工作台。

商机支持见客准备、会后草稿提取与人工确认、增值范围建议、模拟对话和 AI 推进行动。客户反馈与今日待办、材料背景衔接。数据看板包含漏斗、跟进趋势、业务类型与待核实事项。漏斗基于同一组 12 条虚构商机的累计到达阶段；点击阶段可筛选记录。

所有客户、商机、项目、资讯和流程均为虚构演示；不连接营销平台 API 或模型服务。状态仅保存于当前浏览器会话，可重置。支持手机端模块切换、键盘操作与减少动态效果偏好。

## 更新与发布

提交并 push 到 `main` 后，`Deploy portfolio to Tencent Cloud` 自动同步静态网站到腾讯云 `/var/www/stella-portfolio`，也支持在 Actions 页手动运行。GitHub Pages 继续提供备用预览；Netlify Git 构建仍由 `ignore = "exit 0"` 跳过。

自动部署配置：

- Repository Secrets：`DEPLOY_HOST`、`DEPLOY_USER`、`DEPLOY_SSH_KEY`。
- Repository Variable：`DEPLOY_HOST_PUBLIC_KEY`，必须从服务器控制台读取并核对；不能使用未经核对的 SSH 扫描结果替代。
- 部署使用 SSH 严格主机校验，只传输已跟踪的根目录 HTML/CSS/JS 与 `assets/`，不上传 Git、部署脚本、密钥或工作流。
- 每次部署前在服务器用户目录 `~/.local/state/stella-portfolio/backups/` 保存旧网站压缩包。备份需按磁盘容量定期归档；流程不自动删除备份。
- 不删除服务器额外文件，不使用 sudo，不修改 Nginx、营销平台进程或数据库。传输后逐一核验文件 SHA-256；失败时查看 Actions 日志，修正后重新运行。
- 网站目标目录及其子目录须由部署用户可写，服务器需安装 rsync。

本机预览：

```sh
python3 -m http.server 8766 --bind 127.0.0.1
```

打开 http://127.0.0.1:8766/ 。

## 成果与口径

作品集原有成果数字与解释保持不变；不从模拟数据推算真实效果。70% 为情报筛选与整理效率提升，800 万元为潜在线索而非签约收入，20% 为有效商机转化率增幅而非百分点。

## 静态资源缓存

部署时根据 JS/CSS 的文件内容生成带哈希的文件名，并更新所有根目录 HTML 引用，避免新页面误用旧缓存。保留历史版本资源，兼容尚未刷新的页面。源码预览可运行 `python3 scripts/version-static-assets.py .` 更新查询版本。

## 行业研究与项目情报

每日资讯以四个领域、11 个细分方向和七条预设跨领域研究路径展示行业关联。选择节点联动洞察、关联理由和官方历史背景资料；资讯在地图下方通栏排列，可将方向加入研究简报。研究路径为预设分析，不代表实时资讯、因果关系或采购需求。

情报中心围绕具体项目事件，区分预设事实、合作判断与待核实条件；人工确认后关联已有对象，将跟进加入今日工作台。全部项目记录为虚构演示，不写入真实业务系统。

## 手机工作台

手机端底栏提供今日、见客准备、AI 对话、资讯和更多入口。见客准备直接定位当前商机的准备工具；会后录入保留在商机操作中。更多保留客户、商机、项目、情报、材料和数据看板。

手机嵌入窗口按视口限高，内容内部滚动，底栏保持可见；桌面保留侧栏和自动高度。会话按业务背景、预设任务、用户任务与 AI 结果分区，手机选择任务和查看结果后定位对应区域。更多可用 Escape 关闭并返回导航焦点。
