# Stella 个人作品集

纯静态 HTML / CSS / JavaScript，无需安装依赖或构建。

## 打开网站

解压后双击 `index.html` 可浏览。也可在源码目录运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

浏览器打开 http://127.0.0.1:8765 。

## 页面与编辑入口

- `index.html`：封面，保留原有视觉、肖像与联系方式。
- `portfolio.html`：平台案例、三个业务场景、成果、设计取舍、迭代与个人贡献。
- `case-study.css`：案例页的布局与响应式样式。
- `case-study.js`：参考片段切换、跟进确认、章节编辑、TXT 下载与弹窗。
- `about.html`、`capabilities.html`、`career.html`、`toolkit.html`：个人介绍与能力、履历、工具页面。
- `assets/stella-product-manager-resume.pdf`：本次提供的产品经理简历。
- `assets/logistics-network-plan.pdf`：贯穿案例使用的参考方案。

## 演示与实际平台

网站是个人作品集，不连接营销平台 API、数据库或腾讯云。园区、历史方法片段和业务记录是演示案例；情报原文摘自所附方案第 5、7 页，能力摘要根据现有平台配置整理。

跟进确认和章节编辑仅保存在当前页面，刷新恢复初始状态。导出按钮下载真实 TXT 文件，包含当前四个章节、用户编辑与关联背景。实际平台的 Word 导出能力单独在文案中介绍，不将演示 TXT 冒充 Word。

成果数字沿用提供的个人简历：70% 为情报筛选与整理效率提升；800 万元为潜在项目机会；20% 为有效商机转化率提升；1400 万元为加速回款所涉及的待回款项目金额。未补写样本量、观测周期或统计明细。网页中的 72 项测试集表述已改为可检查的业务用例与边界回归实践；简历 PDF 保持原文。
