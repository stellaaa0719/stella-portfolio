在线访问：[Stella 个人作品集](https://stellaaa0719.github.io/stella-portfolio/)

## GitHub Pages 自动更新

发布源为 `main` 分支的仓库根目录。修改后 commit 并 push，GitHub Pages 会自动发布；部署需要短暂等待，不是本地文件实时同步。`.nojekyll` 保持原始静态文件直接发布，无需构建。

## 打开网站

解压后双击 `index.html` 可浏览。也可在源码目录运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

浏览器打开 http://127.0.0.1:8765 。

## 演示与实际平台

网站是个人作品集，不连接营销平台 API、数据库或腾讯云。园区、历史方法片段和业务记录是演示案例；情报原文摘自所附方案第 5、7 页，能力摘要根据现有平台配置整理。

案例页首屏展示平台用途、三类代表性产物与既有核心成果（附简短口径）；下方为一个连续工作区：情报中心 → 商机跟进 → 材料工作台。客户背景跨步骤保留，反馈选择只修改草稿，人工确认后才更新背景与材料。

来源等级与行业/招投标条目均为演示设置，不代表真实采集结果、精确评分或采购事实。实际采集以配置政府/行业栏目与机会公告为主，其他来源可通过指定网址或上传补充；初筛与后续混合检索、rerank 的调用分工在页面可展开查看。

选择“已有供应商”后，材料变为内部回访备忘；其余反馈分别生成访谈或诊断内容。正文依据按钮展示政策/沟通片段；章节和改写为预设前端演示，无文件导出或模型调用。引导逐步由读者点击推进，可跳过、重播、结束与重置；手动选择会结束引导。刷新恢复初始状态。

成果数字沿用提供的个人简历：70% 为情报筛选与整理效率提升；800 万元为潜在项目机会；20% 为有效商机转化率提升；1400 万元为加速回款所涉及的待回款项目金额。未补写样本量、观测周期或统计明细。网页中的 72 项测试集表述已改为可检查的业务用例与边界回归实践；简历 PDF 保持原文。

## 世界星图首页

使用手绘概括大陆多边形生成稀疏星点与邻近连线，不加载地图 SDK、模型 API 或外部数据，无国界、航线或实时数据。默认轮廓已可辨认，鼠标或轻触让局部点回到结构位置；交互停止后缓慢松散。手机端减少星点与连线数量。

点击 Stella 标识（键盘 Enter / Space 同样可用），星点短暂组成 S 后归位。关闭动画或 prefers-reduced-motion 下显示静态星图；彩蛋仅短暂切换静态形态。动画在离屏或切换后台时暂停，Canvas 设备像素比上限为 2。姓名、岗位与入口不参与渐入动画。照片移入后续“关于我”，项目页内容不变。

### 首页星团入口与星尘优化

姓名与职位位于中央略偏下，主项目按钮保留并改为低亮度灰米白。世界星点和细线提亮，文字区域局部降低星点对比。四个不对称星团分别链接到项目经历、核心能力、履历背景、工具方法，支持键盘与触控；手机直接显示全部入口名称。鼠标附近的星芒与短寿命银白星尘提供拖尾，触控出现局部星尘；动态效果关闭时不产生拖尾。粒子数量有上限，离屏暂停逻辑保留。
