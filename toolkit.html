TOOLKIT

工具与方法

围绕任务选择工具，将技术能力用于数据分析、知识调用与产品实现。

01 / DATA ANALYSIS

数据分析工具

SQL

数据提取、校验与业务指标分析；用于风险策略和数据运营实践。

Python

数据清洗、策略测试与分析脚本；帮助减少重复数据处理。

Tableau

数据可视化工具，支持指标理解与分析表达。

02 / AI METHODS

AI 应用方法

AI Agent

组织多步骤业务任务，通过工具调用连接检索、知识调用与行动建议。

RAG

将企业知识接入生成流程；结合混合检索、Rerank 与证据引用优化结果。

Human-in-the-loop

为需求研判和业务行动保留人工确认，区分建议与已核实事实。
